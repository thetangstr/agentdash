# v2026.1014.0

> Released: 2026-10-14.

An agent can no longer keep itself running past its daily token ceiling: its own wakes, its @-mentions of other agents and agent-to-agent review hand-offs now pause at the ceiling, while a person's actions and assignments between agents still run. The agent page also shows the correct time a ceiling pause lifts, and the activity feed names feature flags in plain words.

## Breaking Changes

- **Agent-requested wakes pause at the daily token ceiling.** A wake an agent causes for itself (through the wakeup or invoke routes, a status change on its own issue, creating or reassigning an issue to itself, or its own children-completed and blockers-resolved wakes), an agent's @-mention of another agent, and review, approval or changes hand-offs between agents now count with timer and comment wakes and pause over the ceiling. Over the ceiling the wakeup route answers `202` with `status: "skipped"`, the reason and `liftsAt`. A person's wakes, mentions and review hand-offs, and assignments from one agent to a different agent, still run. The unmetered runaway guard counts these wakes too. ([#1103](https://github.com/thetangstr/agentdash/pull/1103), @thetangstr)

## Fixes

- **Token ceiling lift time.** The agent page said a pause lasted "until Oct 13, 2026 UTC" when it lifts at 00:00 UTC on Oct 14; it now shows the lift time in UTC and in the viewer's local time. ([#1102](https://github.com/thetangstr/agentdash/pull/1102), @thetangstr)
- **Feature-flag activity wording.** Flag changes read "turned on the co-worker bridge feature" instead of echoing the stored key. ([#1102](https://github.com/thetangstr/agentdash/pull/1102), @thetangstr)

## Upgrade Guide

- No migrations. Agents that woke themselves repeatedly will now stop at their ceiling until it lifts; raise an agent's ceiling if that is too early for its work.
