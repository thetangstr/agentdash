# v2026.1009.0

> Released: 2026-10-09.

When an agent hands work to a colleague, the work now goes to the agent that colleague stewards and wakes it, instead of landing on the person as a decision item. This update also adds the gpt-6 Codex models, restores the My agent link to the sidebar, starts per-steward document access with a stricter connection rule, honors HTTP adapter deadlines set in seconds, and opens hosted invitations while keeping the public waitlist.

## Breaking Changes

- **An agent's person assignment goes to that person's agent.** When an agent creates, reassigns or drafts an issue for a person who stewards an active agent, the issue is assigned to that agent and wakes it. The response and activity log record `routedToStewardedAgent`. Send `assignToPerson: true` for a decision only the person can make. People assigning people, an agent handing its own issue back to the person who created it, and stewards whose agent is paused, terminated or pending approval are unchanged. ([#1087](https://github.com/thetangstr/agentdash/pull/1087), @thetangstr)
- **Document connections come only from the steward's own sign-in.** For document providers (`microsoft`, `sharepoint`), an agent resolves only its current steward's private connection. Workspace-visible and agent-owned document connections are refused at creation and never resolved, and the generic connection-create route refuses document providers. Each owner may hold one active `microsoft` connection. ([#1086](https://github.com/thetangstr/agentdash/pull/1086), @thetangstr)

## Highlights

- **Work reaches the agent that does it.** The default mandate, heartbeat guidance, playbook and the `create_issue`, `update_issue` and `suggest_tasks` descriptions tell agents to assign a colleague's agent, using `steward.userId` from `list_agents`. ([#1087](https://github.com/thetangstr/agentdash/pull/1087), @thetangstr)
- **gpt-6 Codex models.** The Codex model picker lists gpt-6.1-sol, gpt-6-astra, gpt-6-sol and gpt-6-luna, all with fast mode. They need Codex CLI 0.160 or later. The default model is unchanged. ([#1084](https://github.com/thetangstr/agentdash/pull/1084), @thetangstr)
- **My agent in the sidebar.** My agent is the first row under Team again; the account-menu entry stays. The Team toggle reads Show team or Hide team. ([#1083](https://github.com/thetangstr/agentdash/pull/1083), @thetangstr)

## Improvements

- **Accurate tool contracts.** MCP tools advertise wrapper descriptions and numeric bounds as validated, and steward clients are directed to `agentdashGetMyMandate`. ([#1082](https://github.com/thetangstr/agentdash/pull/1082), @thetangstr)
- **Hosted invitations.** Hosted signup can admit invited customers through single-use invitations while the public waitlist stays in place. ([#1088](https://github.com/thetangstr/agentdash/pull/1088), @thetangstr)
- **Document access plan.** The per-steward Microsoft 365 document access plan is published; this release ships its first slice. ([#1085](https://github.com/thetangstr/agentdash/pull/1085), @thetangstr)
- **Release verification.** Stable verification is shorter without dropping coverage, and stable decisions stay tied to reviewed source. ([#1079](https://github.com/thetangstr/agentdash/pull/1079), [#1080](https://github.com/thetangstr/agentdash/pull/1080), @thetangstr)

## Fixes

- **HTTP adapter deadlines in seconds.** A finite `timeoutSec` is honored before `timeoutMs`, converted to milliseconds and capped at the timer maximum. ([#1081](https://github.com/thetangstr/agentdash/pull/1081), @thetangstr)

## Upgrade Guide

- One database migration: `0147_document_connection_owner_uq` adds a unique index for active `microsoft` connections per owner. It refuses to apply while any owner holds more than one active `microsoft` connection; revoke the extras first. Apply with migrations allowed.
- Agents that should keep a human-only decision with a person must send `assignToPerson: true`. Existing agents receive the new mandate text through the managed instruction refresh before their next run.
- Move a Codex agent to a gpt-6 model only after the host's `codex` CLI is 0.160 or later.
