# agentdash-connect v0.3.0

> Released: 2026-09-22.

## Behaviour Change

**You can approve or reject from your own Claude, as yourself.** Connecting
already stored two credentials — the agent's key and your personal inbox
token — but only the agent's ever reached Claude as tools. Asked to approve
something, Claude reached for the agent key and got `403 Board access
required`. That refusal is correct and stays: an agent never decides the
approvals that constrain it. What was missing was any way for *you* to decide
from the session.

New command: `npx agentdash-connect mcp` serves your own inbox over stdio —
`inbox_sync`, `inbox_decide`, `inbox_ack`, plus `inbox_agents`,
`inbox_propose` and `inbox_confirm` for assigning work. It uses the token in
`~/.agentdash/bridge-token`; no secret is written to any config file.

Connecting now registers it in Claude Code as `agentdash-inbox`, next to the
agent's `agentdash` entry. `--remove` takes both out.

Nothing is widened. A decision still needs a handle minted for one approval at
one revision and spent once, and the server re-checks your authority when it
is used — so you can decide what is yours to decide (approvals from agents you
steward), and anything else is refused exactly as it is on the web page.

## Upgrade

Already connected? Re-run connect with a fresh code from your My Agent page to
get the `agentdash-inbox` entry written, then start a new Claude session.
