# v2026.925.0

> Released: 2026-09-25.

Two migrations, both additive. This release makes AgentDash drivable from a
personal assistant over MCP (read tools and OAuth sign-in), puts Hermes in the
image as the runtime for hosted boxes, records honest per-run token usage with
a daily ceiling, and lands thirteen security fixes from the September review.
**Read the upgrade notes before updating an existing install:** several
settings that any board user could change before are now instance-admin only.

## Added

- **Assistant MCP, read tools** (#685). Nine task-shaped tools for a personal
  assistant (`whoami`, `whats_new`, `list_projects`, `get_project`,
  `find_work`, `get_work_item`, `explain_blocker`, `list_team`,
  `list_pending_decisions`). Answers are short, bounded and redacted, and carry
  deep links. `AGENTDASH_TOOLSET=assistant` selects them on stdio. The existing
  journey tools stay the default for agent keys.
- **OAuth 2.1 for assistants** (#688). The instance is its own authorization
  server: `/.well-known/oauth-*`, `/oauth/register|authorize|token|revoke` and
  a remote streamable-HTTP endpoint at `/api/mcp/assistant`. PKCE S256 only,
  single-use codes, rotating refresh tokens, DCR and CIMD, and a built-in
  `muse` client pinned to Meta's callback. An assistant token (`pcpa_`)
  reaches no raw REST route. Tools read through a short-lived in-process
  credential instead.
- **Hermes in the Docker image** (#738), pinned to v2026.9.11 and installed
  from hash-checked wheels only. Hermes state lives on the volume under
  `/paperclip/.hermes`.
- **Hermes provider key in onboarding** (#739). The key is validated with one
  call and stored as an encrypted company secret. It is written to profiles
  with mode 0600 and never passed on a command line.
- **Honest per-run record** (#704). Each run records the served model, tokens
  (read from the Hermes profile ledger), wall time, time to first output,
  outcome and wake reason. When usage can't be read, the run is marked
  `unmetered` instead of showing 0.
- **Daily token ceiling** (#705). The default is 5M tokens per agent per UTC
  day, counting input plus output, with cached input counted as input. It
  pauses only timer and comment wakes. Assigned and manual work still runs.
  The pause shows on the agent page and in the activity log. A backstop also
  pauses runaway runs that should have been metered but weren't. Set the
  ceiling to `0` to turn both off.
- **Stuck vs quiet for Hermes** (#703). Liveness comes from the process and
  ledger activity, so long quiet Hermes runs no longer open "stuck run"
  tickets. The first-output deadline runs in **shadow mode** by default: it
  records `would_stop_no_first_output` and stops nothing. Set
  `AGENTDASH_FIRST_OUTPUT_DEADLINE_MODE=enforce` or the per-agent
  `firstOutputDeadlineMode` to enforce it. Includes upstream `1e8ede4e1`.
- **Hosted boxes** (#729, #730). With `AGENTDASH_DEPLOYMENT_KIND=hosted`, the
  server refuses to boot unless it runs in authenticated mode on https with
  managed Hermes profiles, gated signup, no placeholder invite codes and the
  anonymous trial off. A hosted box holds one company, and SSO signs in
  existing users only. `doc/runbooks/hosted-box.md` and `scripts/hosted/`
  provision, claim, back up and restore a box on Railway.

## Security

- Tenant binding fixes for conversations and onboarding (#692) and mandates
  (#715). Slack and Gmail send, read and draft are bound to the authorized
  connection, including when acting through a stewarded agent (#713, closes
  #720).
- Instance-admin gates for host command execution in agent config, the
  adapter test environment, setup-adapter, imports and issue overrides
  (#714), workspace provision, teardown and runtime-service commands (#742),
  and instance-global plugin state and the handshake demo (#718).
- Agent keys can change only a short allowlist of fields, on themselves
  (#716) and on other agents (#728).
- Instruction bundles are confined to company directories, and Hermes `-p` is
  pinned to the agent's own profile (#741). Workspace archive deletes are
  confined (#717).
- Deleting a company works after an assistant has connected, and a founder
  who opens `/cos` first becomes the instance admin (#746).

## Upgrade notes

- **Migrations:** `0129` adds the assistant OAuth tables and `0130` adds one
  nullable column. Both are additive.
- **New public endpoints on every install:** the OAuth metadata and endpoints
  above, plus `/api/mcp/assistant`. Anyone can register a client without
  signing in (30 clients by default).
- **Instance admin only, in authenticated mode:** custom agent command, args,
  env, working directory and path settings; workspace provision, teardown and
  runtime-service commands. Values already saved keep working, and resending
  them unchanged is accepted. `local_trusted` installs are unaffected.
- **Project env:** execution-affecting keys (for example `PATH`, `GIT_*`,
  `*_BASE_URL`, `ANTHROPIC_*`, `OPENAI_*`, `HERMES_*`, `HOME`, `TMPDIR`) are
  dropped at run time, including keys saved before this release. Any edit
  that still includes one, or a key that isn't upper-case, returns 422. Remove
  those keys before editing a project's env.
- **Agent keys:** an agent can change only `name`, `title`, `icon` and
  `capabilities` on itself, plus `desiredSkills` on another agent. A CEO-agent
  routine that edits role, status, reporting line, budget, runtime or adapter
  config now gets a 403.
- **Instruction bundles** refuse symlinks inside the bundle root. New roots
  must sit under `<instance>/companies/<id>/...` unless set by an instance
  admin.
- **Docker image:** defaults to `AGENTDASH_HERMES_MANAGED_PROFILES=true` and
  `AGENTDASH_DEFAULT_ADAPTER=hermes_local`. The container starts as root,
  hands `/paperclip` to `node`, then runs as `node`, so the first boot on a
  large volume is slower. Leave Railway's run-as-user override unset.
- **Hermes command:** a bare `hermes` is resolved to an absolute path at boot.
  Restart after moving or reinstalling Hermes. Hermes runs now record a pid,
  so after a restart a live run is left detached and a dead one is marked
  `process_lost` and retried once, as Claude and Codex runs already are.
- **Invite codes:** when `AGENTDASH_REQUIRE_SIGNUP_INVITE_CODE` is on, MCP
  signup also needs a code from the instance's own `AGENTDASH_INVITE_CODES`.
- **Backfill is manual:** `server/scripts/backfill-run-facts.ts` fills
  per-run records for the last 30 days. Run it with `--dry-run` first.
- No new required environment variables outside hosted boxes.

## Known issues

- Teammates can't yet join a hosted box whose public signup is closed (#731,
  in review as #743).
- A company with rows in some older tables still can't be deleted (#748).
