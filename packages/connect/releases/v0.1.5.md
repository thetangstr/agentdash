# agentdash-connect v0.1.5

> Released: 2026-08-27

## Highlights

- Restores AgentDash's package-specific release boundary: only the owned `agentdash-connect` package can be selected by the fork's npm publishing path.
- Keeps the existing `agentdash-connect-v0.1.x` tag and npm lineage; inherited `@paperclipai/*` packages and unprovisioned `@agentdash/*` names are excluded and cannot be version-rewritten by this release control.

## Runtime behavior

The connector runtime payload is unchanged from `0.1.4`. This patch release records and verifies the corrected publishing, provenance, and GitHub Release controls without changing how Claude Code or Codex connects to AgentDash.

## Provenance

- Application/OTA source: `f552df77417143fd6a949eff8553b98578317f5e`
- Connector source and release control: the reviewed `main` commit targeted by `agentdash-connect-v0.1.5`; its exact SHA is recorded by npm's trusted-publishing attestation and the attached release manifest.
- Publisher: `.github/workflows/publish-connect.yml` through npm trusted publishing/OIDC. No long-lived npm token is used.

The GitHub Release attaches the exact packed tarball, its SHA-256 checksum, and a JSON manifest binding the package version to both source SHAs.

## Upgrade

```sh
npx agentdash-connect@0.1.5
```

Existing `0.1.4` installations do not require a configuration migration.
