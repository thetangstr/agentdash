# v2026.1013.1

> Released: 2026-10-13.

A person's send-back, change request or answer to an agent's question now wakes the agent even when it is over its daily token ceiling, and only company or instance administrators can change a company's feature flags.

## Breaking Changes

- **Only administrators change feature flags.** `PUT /api/companies/:companyId/feature-flags/:flagKey` now requires a company owner or admin, or an instance admin. Agent keys and ordinary members get 403. Each change is recorded in the activity log with the previous and new value. ([#1099](https://github.com/thetangstr/agentdash/pull/1099), @thetangstr)

## Fixes

- **A person's decision wakes the agent over its token ceiling.** A bridge send-back, a requester's change request, and a person's answer to an agent's question (from the web or the bridge) were classed as comment wakes, so the daily token ceiling paused them. They now carry the wake reasons `bridge_reply`, `changes_requested` and `interaction_resolved`, which count as deliberate only when a person requested the wake; an agent cannot claim them. The send-back read-back now says when the agent will not be woken, and confirm returns `notWokenReason`. ([#1100](https://github.com/thetangstr/agentdash/pull/1100), @thetangstr)

## Upgrade Guide

- No migrations.
