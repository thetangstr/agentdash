# v2026.1001.2

> Released: 2026-10-01.

The launch-day security release: the release AgentDash Cloud design-partner boxes run. No box-side migrations. Everything merged since the v2026.1001.1 source (`2d8b576ee`).

## Security

- **Live events stop when access ends** (#931, GH #708). A live-event socket is closed (code 1008) as soon as its subscriber loses access: membership removed or downgraded, agent key revoked, agent terminated or deleted, user sessions revoked, board ownership claimed. A heartbeat re-check closes sockets whose access was removed out of band, failing closed on errors.
- **Company import can't be pointed at internal addresses** (#932, GH #709). The GitHub fetch behind company and skill import allows only GitHub hosts (plus `AGENTDASH_GITHUB_ALLOWED_HOSTS` and existing GitHub Enterprise settings), re-checks every redirect, refuses private, loopback, link-local and metadata addresses, pins the checked IP, and caps size (20 MB) and time (30 s). **Upgrade note:** a GitHub Enterprise host on a private network needs `AGENTDASH_GITHUB_PRIVATE_HOSTS`; loopback and metadata stay blocked even then.
- **Routines need permission to change** (#935, GH #710). Every routine write (create, edit, run, trigger create, update, delete and secret rotation) needs `tasks:assign`; agents always get 403. A company import containing recurring tasks runs the same check before writing anything, and imported routines arrive paused.
- **Restricted projects stay hidden in budgets** (#930, GH #902). The budget overview, budget-override approvals, budget writes, dashboard counts and issue cost totals leave out projects the viewer can't see.
- **Member emails stay private** (#945, GH #505). Agents never receive member email addresses; members see only their own unless they manage members. Profile links no longer derive from email, and an email can't be used to probe membership. Agents are told `email` is always null for them.

## Fixed

- **On-volume backups keep the whole schema** (#929, GH #907). Backups now include CHECK constraints (NOT VALID ones after the data), views, functions and triggers (with their enabled state), in dependency order, so a restore comes back with the evaluation-ledger lock and full integrity. A refused COPY fails the restore instead of hanging.
- **Claiming a hosted workspace lands you in it** (#949). Right after the claim, the app no longer shows "No company access" until a reload: access is refreshed when the first company is created, and the gate re-checks once before showing that page. The claim page's "Sign in" goes to the workspace's own sign-in, and www-only pages (`/start`, `/find`) on a workspace redirect there instead of failing.
- **Backups round-trip every value** (#943, GH #940). The INSERT path no longer corrupts bytea, shifts naive timestamps by the host time zone, or fails on arrays; this also fixes worktree seeds.

## Changed

- **Site copy** (#942). Demo spend figures no longer quote invented dollar amounts; approval prompts say "your approval"; `/assess` sends visitors to `/start`; a hosted-box support runbook.
