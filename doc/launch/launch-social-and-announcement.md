## Announcement (email / Discord / Slack / GitHub Discussion)

**Subject / title:** Introducing AgentDash — a Chief of Staff agent that answers to you

We're releasing AgentDash: the control plane for running an agent company with human stewards in the loop.

**What it is**
Hire a Chief of Staff agent, direct it from Claude Code or Codex, and let it coordinate the rest of your agent workforce. Every agent has an accountable human. Hires, spend, deletions, and outside contact wait on your decision.

**What's under the hood**
Built on open-source Paperclip. AgentDash adds the steward relationship, a harness-side inbox via MCP, and human-in-the-loop controls (approvals bound to a revision, budget hard-stops, activity log).

**How you get it today**
- Install yourself (available now)
- Limited managed pilots for design partners
- Hosted AgentDash — in design; join the interest list

**Not this**
Not a chatbot. Not a free cloud trial. Not invented customer logos.
