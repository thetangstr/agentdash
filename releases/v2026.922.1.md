# v2026.922.1

> Released: 2026-09-22.

No migrations. One fix, found live within the hour of v2026.922.0 reaching its
first real steward.

## Fixed

**Teams Workflows webhooks dropped every message we sent.** Power Automate
accepts any POST with HTTP 202 and only afterwards decides whether to post it
— and the Teams "post to a channel" flow template posts Adaptive Cards, not
plain `{text}`. So the challenge message, and every digest after it, was
"delivered" by our cursor's accounting and never appeared in the channel.
Verified live against a real Workflows URL: plain text vanished, a card
posted.

Webhook bodies are now host-aware: URLs on `*.powerplatform.com` and
`*.logic.azure.com` get the digest wrapped in an Adaptive Card — one TextBlock
per line, raw URLs turned into tappable links, and a single
"Decide on AgentDash" button. That button is `Action.OpenUrl` and that is the
only action kind the card may ever carry: a Submit action would come back
through the flow with no verified sender, which is exactly what this transport
is forbidden to do. Deciding stays on the AgentDash page. Every other webhook
host keeps plain `{text}`.

Existing registrations need nothing: the fix is in the sender. A steward whose
digests went missing will get the next one as a card.
