# v2026.1002.0

> Released: 2026-10-02.

The first-session release: everything the launch-day end-to-end and from-scratch UX scans found. No migrations. Everything merged since v2026.1001.2 (`3948fcb85`).

## Changed

- **One first-run path for every install** (#956). Hosted and self-hosted founders both go /company-create → /setup → the Chief of Staff (CoS) at /cos. "New Company" starts the same flow. The old wizard is still reachable at /onboarding. Self-hosted /setup checks or switches the runtime (Claude Code, Codex, Hermes); switching is instance-admin only.
- **The CoS first session works without a nudge** (#953). Once the interview has enough, the plan card arrives in the same reply. Hired agents keep their proposed role, and privileged roles (CEO, Chief of Staff) are never handed out by a plan. The model-key step lands on the CoS. The Ask page opens with a greeting and role-neutral suggestions.
- **Ask lives in the app** (#958). It sits at /:prefix/cos inside the sidebar layout, and bare /cos redirects there. It never shows another company's conversation, and switching company clears the old chat.
- **Reviews reach you** (#952). Deliverables waiting on your review appear in Waiting on you and Decisions. They are routed to the requester, else the agent's steward, else admins, and filtered by agent and project visibility. Accepting a task (moving it to done) marks its deliverables accepted, and reopening it reverts that.
- **Home** (#951). Spend shows tokens with "billed by your model provider" when cost isn't metered, filtered by visibility. "Connect GitHub" is optional and dismissible.
- **Onboarding wizard** (#955). Wizard tasks are parked with a Start button, so nothing runs until you say so. The workspace owner becomes steward of their first agent. "New Company" is hidden on hosted boxes. On self-hosted installs, `/` goes to sign-in or the app; www always shows the marketing site, decided by hostname. A brand-new instance opens on "Create your workspace". The copy is plain language.
- **Settings opens the workspace** (#957). Legacy /settings links keep their company. Instance settings are shown only to instance admins. A "Slack connected" confirmation was added.

## Fixed

- **No premature "Recover stalled issue"** on a new company (#957). Escalation waits until an issue is 10 minutes old, and a same-agent run that is still live counts, capped at 1 h silent or 4 h running. Exhausted retry budgets are still held immediately.
- **Links use the public address** (#950). Invites, CLI sign-in, emails, billing and Slack return URLs are built from the configured public URL, not a box's Railway host or the request Host header.

## Security

- **Bootstrap can't make you owner** (#956, #959). Setting up the CoS in an existing workspace needs its owner or admin, and never rewrites an existing role. Archived workspaces are refused. A `companyId` you aren't an active member of gets 403 with no fallback, including for instance admins. A same-email-domain signup no longer auto-joins (or owns) an existing workspace; ask its administrator for an invite.

## Upgrade notes

- Coworkers no longer join a workspace automatically by signing up with the same work-email domain. They need an invite.
- Boxes behind the edge router need no change. Self-hosted installs with several addresses should set `PAPERCLIP_PUBLIC_URL` so links use the address people actually reach (#954 tracks the config-file case).
