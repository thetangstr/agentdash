# v2026.1008.0

> Released: 2026-10-08.

Hermes SSH invocation records now preserve a configured absolute remote executable, the actual ordered arguments beginning with `chat`, and the SHA-256 of the exact rendered UTF-8 query. Prompts stay in private files. This update also strengthens agent and approval permissions, keeps financial information private, and makes public product updates and documentation easier to find.

## Breaking Changes

- **Unavailable financial amounts are unknown.** Company and agent `budgetMonthlyCents` and `spentMonthlyCents` can now be `null` for readers without spend access, including mutation responses, configuration history and hire approvals. Restricted budget-approval amounts are omitted, and the budget overview returns 403 without spend access. Clients must handle unavailable values without treating them as zero. ([#1074](https://github.com/thetangstr/agentdash/pull/1074), @thetangstr)
- **Agent hiring cannot grant privileged authority.** Agent callers, including CEO agents, receive 403 when creating a CEO or Chief of Staff or granting `permissions.canCreateAgents: true`. A board administrator must create these privileged agents. Ordinary hires remain supported. ([#1074](https://github.com/thetangstr/agentdash/pull/1074), @thetangstr)
- **Approval channels must match their trusted source.** REST approval decisions cannot claim a connector channel. Use the authorized web decision path; `channel: "assistant"` requires an authenticated assistant grant. Connector provenance is supplied by the trusted connector itself. ([#1074](https://github.com/thetangstr/agentdash/pull/1074), @thetangstr)
- **Remote Hermes needs query-file support.** SSH execution now requires `hermes chat --query-file`. Unsupported remote versions fail with an upgrade instruction; prompts are never substituted into command arguments. Conflicting query options in `extraArgs` are refused before SSH starts. ([#1075](https://github.com/thetangstr/agentdash/pull/1075), @thetangstr)

## Highlights

- **Accurate SSH invocation records.** The `adapter.invoke` event contract reports the configured remote executable, preserving absolute paths, and the complete ordered `commandArgs` beginning with `chat` and including the private `--query-file` path. `promptSha256` remains the lowercase SHA-256 of the exact rendered UTF-8 query. Metadata excludes SSH and environment-wrapper arguments, query bytes and environment values. The event is emitted after private staging succeeds, just before launch. ([#1075](https://github.com/thetangstr/agentdash/pull/1075), @thetangstr)
- **Public product updates.** A What's New page links to dated updates about teams, live transcripts and run logs, with article navigation from the public site. These pages describe release changes without claiming a particular instance has received them. ([#1072](https://github.com/thetangstr/agentdash/pull/1072), @thetangstr)
- **Reachable documentation.** Public docs and deep links are reachable from the site, with Guides and MCP discovery links and neutral first-run company setup guidance. Browser release notes are sanitized before bundling. ([#1076](https://github.com/thetangstr/agentdash/pull/1076), @thetangstr)

## Improvements

- **Private SSH prompts and safer target changes.** Prompts and run environment values travel through private files rather than process arguments. Changing a pinned Hermes SSH target or driver requires human agent-management authority and an operator-allowlisted target, including during concurrent configuration changes. Cleanup failures are reported. ([#1075](https://github.com/thetangstr/agentdash/pull/1075), @thetangstr)
- **Remote session usage.** Hermes SSH runs can read usage from the completed session's attributable remote ledger. Missing or unreadable usage remains explicitly unknown. Keep wall-clock and turn limits when usage cannot be measured. ([#1075](https://github.com/thetangstr/agentdash/pull/1075), @thetangstr)

## Fixes

- **Financial privacy across response paths.** Company summaries, agent rows, activity, approvals, inboxes and configuration responses consistently apply spend permissions. Members retain nonfinancial budget-stop status and administrator escalation guidance. ([#1074](https://github.com/thetangstr/agentdash/pull/1074), @thetangstr)
- **Workspace-operation log access.** Logs and related lists require access to both linked workspace and run; unresolved or inconsistent links fail closed. ([#1074](https://github.com/thetangstr/agentdash/pull/1074), @thetangstr)
- **Responsive privacy processing.** Feedback, workspace-operation logs and recovery evidence yield during privacy processing. Decoded NDJSON keys and values are sanitized while preserving valid records and colliding values; truncation retains whole records. Cooperative processing does not impose a hard latency bound on a single oversized record or regex search. ([#1077](https://github.com/thetangstr/agentdash/pull/1077), @thetangstr)
- **Recover input held by an inactive owner.** The recovery API lets the exact active current accountable human review safe recovery metadata and explicitly confirm cancellation without reading the original owner's private question or answer. The workforce panel offers this path even when readiness is unavailable. Administrator status alone does not grant recovery authority. ([#1078](https://github.com/thetangstr/agentdash/pull/1078), @thetangstr)

## Upgrade Guide

- Update API clients to accept nullable monthly finance fields and omitted restricted approval amounts. Display unavailable values as unknown and retain administrator escalation for budget stops.
- Route privileged hires, SSH target changes and approval decisions through the authorized human or trusted connector path. Do not retry a permission refusal with another route or a claimed channel.
- Before enabling a Hermes SSH target, verify that its configured remote executable supports `chat --query-file`; upgrade that installation if needed. Capability must be checked for each target, and no general upgrade or rollout is implied. Unavailable metering is unknown usage; retain timeout and turn limits.
- When a new Hermes session is required, configure `persistSession: false` and omit session, resume and fork flags from `extraArgs` for that target. This is configuration guidance; it does not change the adapter's existing session-resume behavior.
- For paged workspace-operation logs, follow `nextOffset` as a raw stored-byte cursor; do not calculate it from the redacted response length.
- Inactive-owner recovery requires explicit cancellation, canonical replacement with `human_questions.replace`, then a genuine answer through the normal response path. Cancellation records a receipt; it supplies no answer, creates no wake and does not release required input. The replacement answer lets the same task continue through normal run gates. If acknowledgment is lost, read current canonical state before another action.
- No database migrations or new dependencies are required in the reviewed change range. The existing Hermes adapter patch changes, so install the release's lockfile rather than retaining an older patched adapter.
