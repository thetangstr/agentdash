# Ross governed lead report pilot

Objective: replace operator-curated lead material with an actual designated lead's fresh model report, under AgentDash authentication and checkout. This bounded step does not establish continuous reporting or complete Ross acceptance.

The lead receives its own owner-private runtime and explicit source-only MCP configuration. It uses the same exact `glm-5.3-flash`/Z.AI route and two project-scoped read tools. Ross's private commitment projection and identity are not inherited by the lead.

After a genuine governed inference receipt, the runtime rechecks actor, designated project lead, running run, assigned issue and exact checkout. It publishes the model's exact answer to the existing `lead-report`, using the prior revision as a compare-and-set guard. It verifies API authorship, incremented revision and exact readback, and records private intent/publication receipts. The model receives no write tool. An ambiguous write leaves a reservation and must be inspected rather than retried automatically.

Verification: role/source-only behavior, real HTTP method/auth headers, exact report publication, foreign scope/checkout/route/session refusal, same-run duplicate refusal, revision conflicts and changed readback. Fresh local evidence: 132 Node tests pass; 8 scoped Vitest tests pass, with 2 optional startup probes skipped; profile compilation and source syntax/diff checks pass. Independent review approved the source lane.

Actual acceptance requires one manually dispatched lead run, exact private model/session evidence, a new lead-authored report revision and matching run-attributed comment. Ross's subsequent fresh read and useful response are a separate acceptance step. Report claims remain reported rather than independently verified business outcomes.

Preserve existing lead report history, issue description and unrelated agents/services. Restore the pilot to paused with timer/demand wakes disabled after the terminal run. No push, production package replacement, service restart, migration, recurring schedule or Tailscale change.

Evidence is retained in the private lead checkpoint directory (operator-private evidence). AgentDash launch ownership and acknowledgment status remain in the coordination brief (operator-private evidence).
