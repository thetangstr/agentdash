# v2026.1014.1

> Released: 2026-10-14.

An agent's memory and the lessons it learns from corrections are now private to the agent, its steward and administrators. Other members and other agents can no longer read them through the memory routes, run records, run logs or feedback bundles, and runs recorded before this release are cleaned. Stewards get a read-only Memory section on the agent page.

## Breaking Changes

- **Agent memory is readable only by the agent, its steward and administrators.** `GET /api/companies/:companyId/agents/:agentId/memory` and `GET /api/companies/:companyId/agents/:agentId/memory/history` answer the agent itself, its active steward, company owners and admins, and instance admins; everyone else, including other agents, gets `404`. `agentdashGetMyMemory` follows the same rule. Writes are unchanged. ([#1104](https://github.com/thetangstr/agentdash/pull/1104), @thetangstr)
- **Memory and corrections are withheld from run records.** The saved run context, the `adapter.invoke` event (prompt, context and wake payload), live events, run detail and run events no longer carry the agent's memory or its "what changed" corrections; the agent still receives both during its run. ([#1104](https://github.com/thetangstr/agentdash/pull/1104), @thetangstr)

## Fixes

- **Run logs withhold memory traffic and lesson echoes.** Members still read agents' run logs. The content of memory reads and writes (claude and codex tool calls, `api_request` and curl to the memory route) and repeats of the run's memory or delivered corrections are replaced with a withheld marker, in the log file, excerpts, live log events, run results and errors. Logs written before this release are cleaned when read. ([#1104](https://github.com/thetangstr/agentdash/pull/1104), @thetangstr)
- **Feedback bundles leave out lessons.** Run context, events and run logs in feedback bundles are cleaned, and adapter transcripts are left out for agents that have memory or corrections. ([#1104](https://github.com/thetangstr/agentdash/pull/1104), @thetangstr)
- **openclaw_gateway no longer logs corrections** in its outbound parameters. ([#1104](https://github.com/thetangstr/agentdash/pull/1104), @thetangstr)
- **Memory on the agent page.** A read-only Memory section, newest version first, shown only to the agent's steward and administrators. ([#1104](https://github.com/thetangstr/agentdash/pull/1104), @thetangstr)
- **Agent instructions.** The learning-loop block now says who can read memory and asks agents not to quote their memory or lessons verbatim in comments, documents or summaries. Existing agents receive it when their managed instructions refresh. ([#1104](https://github.com/thetangstr/agentdash/pull/1104), @thetangstr)

## Upgrade Guide

- One migration, `0152_withhold_agent_lessons_from_runs`. It removes memory and corrections from runs created since 2026-08-20 that carried them, and from their `adapter.invoke` events, in one transaction at startup. Back up before applying. Old log files are not rewritten; they are cleaned when read.
