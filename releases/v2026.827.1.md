# v2026.827.1

> Released: 2026-08-27

## Critical OTA Correction

- **Native macOS readiness now parses correctly** — The source-checkout release-control asset now escapes the `Bearer ` case pattern in the generated readiness wrapper so the macOS system Bash can parse and run the canonical post-restart health gate.
- **`v2026.827.0` is superseded for native installation** — Its application source remains valid, but its generated readiness wrapper exits with a Bash syntax error before a successful deployment receipt can be written. Native operators must use the checksummed `v2026.827.1` control asset instead.

## Application Payload

The application payload remains exact source `f552df77417143fd6a949eff8553b98578317f5e`. It includes resumable invited-user onboarding, truthful shared open-task counts, run-attributed issue comments, aggregate recovery limits, configured cost visibility, and bounded idle polling. This patch changes only the reviewed release-control renderer and its regression coverage.

## Upgrade Guide

This remains an in-place source-checkout upgrade. Preserve the existing database, configuration, storage, and agent data; do not reinstall or reimport the instance.

Download these assets from this GitHub Release:

- `agentdash-mac-mini-source-launchd-v2026.827.1.mjs`
- `agentdash-mac-mini-source-launchd-v2026.827.1.mjs.sha256`
- `agentdash-release-control-v2026.827.1.json`

Verify the updater checksum and confirm that the manifest records source SHA `f552df77417143fd6a949eff8553b98578317f5e`. Run the downloaded control script without `--write` first. Refresh the wrappers while the currently installed SHA remains pinned, then invoke the generated `agentdash-source-update.sh` with the exact target SHA. Require the wrapper to complete readiness and emit a deployment receipt. A healthy HTTP response without a successful wrapper exit and receipt is not an accepted upgrade.

Before upgrading, back up the database and run this read-only duplicate preflight:

```sql
SELECT company_id, created_by_user_id, COUNT(*)
FROM onboarding_sessions
GROUP BY company_id, created_by_user_id
HAVING COUNT(*) > 1;
```

Stop if the query returns any row. Otherwise, allow the normal startup migration path to apply only pending migrations. Do not run ad hoc `git pull`, replace the installation, or restore a database backup without explicit operator approval.
