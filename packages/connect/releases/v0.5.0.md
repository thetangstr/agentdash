# agentdash-connect v0.5.0

> Unreleased. Not published to npm. Expected to ship after v0.4.0, which is
> on a separate branch and merges first.

## Behaviour Change

**Upload and share your own files from your own session.** When document
access is on for your company, the `agentdash-inbox` tools gain four upload
tools, and connecting installs the `agentdash-upload` skill that walks a
request through: which file, which folder in your own OneDrive, who gets view
or edit access, which task it belongs to; one read-back; one yes.

- `upload_destinations`, `upload_propose`, `upload_confirm`, `upload_cancel`.
- The file is read only from the path you gave: one regular file, no symlinks
  or folders, never from a credential folder (`~/.agentdash`, `~/.ssh`,
  `~/.claude`, `~/.codex`, `~/.gnupg` and similar), `.pptx`/`.docx`/`.xlsx`/
  `.pdf` whose content matches, 250 MB at most.
- Only the file's name, size, type and SHA-256 go to AgentDash until you say
  yes; the bytes then go in 10 MiB pieces, and AgentDash uploads them to
  Microsoft as you. This machine never receives Microsoft's upload address or
  any Microsoft token.
- If the file changes between the read-back and your yes, nothing is uploaded.
- An interrupted upload resumes from where Microsoft says it stopped.

**Codex gets the inbox tools too.** Connecting now writes
`[mcp_servers.agentdash-inbox]` to `~/.codex/config.toml` (a `command` and
`args`, no secret), next to the agent's entry. `--remove` takes it out.

**The `agentdash-upload` skill** is installed to
`~/.claude/skills/agentdash-upload/` and `~/.codex/skills/agentdash-upload/`
for the harnesses present. A skill of that name you wrote yourself is left
alone, by install and by `--remove`.

## Upgrade

Re-run connect with a fresh code from your My Agent page. Uploads need a new
permission on your machine's inbox credential (`bridge:upload`); a machine
paired earlier gets `403` from the upload tools until it re-pairs. Then start
a new Claude Code or Codex session.

Requires an AgentDash server with person upload (document access slice 8),
the company's document access switched on, and Microsoft connected from My
Agent with the tier that can save files.
