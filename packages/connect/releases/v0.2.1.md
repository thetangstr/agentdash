# agentdash-connect v0.2.1

> Released: 2026-09-15

Field findings from the first two stewards through the 0.2.0 flow, fixed.

## Highlights

- **Every pairing and every inbox render now names its owner.** "Inbox
  connected for Chris Hong (…)" at pairing; "AgentDash inbox — Chris Hong" on
  every read. A machine can hold the wrong person's credential — it happened on
  a shared machine, silently — and the only reader who can notice is one who is
  told a name they do not answer to.
- **Replacing another person's inbox connection is now a question, not a side
  effect.** The owner is stored beside the token (display metadata only, mode
  600); a pairing that would hand the inbox to a different person asks first
  and defaults to keeping what is there. The agent pairing proceeds either way.
- **The delivered text stops naming a tool the session cannot call.** The hook
  closed with "Decide with the inbox_decide tool"; deciding in-session is not
  wired yet, and the first steward through said so. It now points at the
  AgentDash page. The scaffolded README's same overpromise is corrected.
- **Device names carry the platform** — `hostname (win32)` — so "what OS was
  that pairing?" is answerable from the audit trail. It was asked, and nothing
  recorded had the answer.

## Compatibility

- Older instances report no owner; every owner-aware feature degrades to the
  0.2.0 wording and behaviour. No flags changed, no paths moved.
