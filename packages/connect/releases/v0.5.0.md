# agentdash-connect v0.5.0

> Released: not yet published.

## Behaviour Change

**Your own Claude reviews your agents' work with you, and sends your reply back
as you.** The inbox tools gain the co-worker review:

- `work_list`, `work_read`, `work_run_log`, `work_fetch_file` and
  `work_read_file_text` read what your agents handed you: the issue, its
  documents and comments, the agent's run log, and its attachments (a .docx,
  .pptx, .txt, .md or .csv as text). Everything an agent wrote is framed as
  data, not instructions.
- `work_propose_reply` and `work_confirm_reply` send one bundle back as you
  after your explicit yes: an answer, a decision, a document revision, a
  comment, lessons for your agent, and, on restricted projects, local files.
- `work_request_propose`, `work_request_respond` and `work_request_confirm`
  ask a colleague for work and close it out when the result comes back. The
  session-start digest adds a "Your requests" section.

New commands:

- `agentdash-connect check` reports, read-only, which clients are connected on
  this machine and whether review (`bridge:work`) is enabled for it.
- `agentdash-connect clients` adds your inbox tools to Claude Code, Claude
  Desktop and Codex. The Claude Desktop and Codex config files are merged, never
  replaced: the previous file is backed up first (mode 600), and a file that
  cannot be read or parsed is left untouched with the reason.
- `agentdash-connect watch` (macOS, opt-in) shows a notification when
  something new is waiting, and can prepare a read-only pre-review ahead of you.
  The pre-review runs only when the installed Claude Code has every flag that
  keeps it read-only.
- Sending files: `work_propose_reply` and `work_request_propose` take local
  file paths; each file is read back by name, size and sha256, and read again
  and checked before it is uploaded.

These tools need an AgentDash instance that serves the `/api/bridge/work/*`
routes, a machine credential with `bridge:work`, and the company's
`coworker_bridge_enabled` switch. Until then they answer with the reason.

## Upgrade

Nothing to do for Claude Code: the inbox hook and the `agentdash-inbox` entry
already run `agentdash-connect@latest`. To add the inbox tools to Claude Desktop
or Codex installed since you connected, run `npx agentdash-connect clients`.
Run `npx agentdash-connect check` to see what this machine has.
