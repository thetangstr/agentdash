# v2026.1010.1

> Released: 2026-10-10.

Inbox email pointers are now off by default. Agent questions and decisions reach people in their own Claude or Codex session through the bridge inbox and on Home in AgentDash; an instance sends inbox emails only when an operator turns them on.

## Behaviour Change

- **Inbox emails are opt-in per instance.** The pointer emails added in v2026.1010.0 run only when `AGENTDASH_INBOX_EMAIL=true` is set alongside `RESEND_API_KEY`. Without it no inbox email is sent, and the My Agent email switch is hidden. Transactional email (invites, password resets) is unaffected. ([#1096](https://github.com/thetangstr/agentdash/pull/1096), @thetangstr)

## Upgrade Guide

- No migrations. To keep inbox emails on an instance that wants them, set `AGENTDASH_INBOX_EMAIL=true`.
